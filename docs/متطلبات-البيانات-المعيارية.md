# متطلبات البيانات المعيارية وإدارة الاستيراد

## الغرض والنطاق

تحدد هذه الوثيقة متطلبات أن تكون قاعدة SQLite المحلية المشفّرة مرجع البيانات المعتمدة، وأن تكون ملفات Excel ومصادر الإدخال الأخرى وسائل لإيصال بياناتها لا مخططًا ملزمًا للنظام. يُشغّل التطبيق دون نموذج ذكاء اصطناعي محلي أو خدمة تحليل خارجية. الاتصال التلقائي بقناة GitHub Releases استثناء تشغيلي مستقل عن معالجة البيانات، ويتطلب اتصالًا عند فحص تحديث أو تنزيله.

## المتطلبات الوظيفية

1. **قاعدة معيارية مستقلة:** تمثل الحقول والكيانات والعلاقات والفترات والوحدات ومصادر القيم في قاعدة النظام. تبقى الجداول القديمة خلال الترحيل التوافقي؛ لا تُمحى بياناتها أو نتائج التحليل المقبولة.
2. **تعريفات قابلة للمراجعة:** لكل حقل تعريف ونوع ووحدة وحالة إدخال وقواعد تحقق، وتُحمّل النماذج المنشورة من قاعدة البيانات. لا تُنشأ تعريفات رسمية للنماذج الـ105 غير المتوفرة مصادرها.
3. **إدخال يدوي موحد:** يحفظ الإدخال كمسودة مع حالة القيمة والمصدر والتاريخ، ويمر الإرسال والمراجعة والاعتماد عبر انتقالات صريحة وسجل نسخ وتدقيق. لا تُعدل السجلات المعتمدة مباشرة؛ إعادة الفتح تتطلب قرارًا مسببًا.
4. **استقبال ملفات متباينة:** يفحص ملف Excel المسموح به ويؤرشف نسخته الأصلية وبصمته والأوراق والصفوف والخلايا ومواقع المصدر والصيغ والقيم المخبأة والوسائط القابلة للاستخراج ضمن حدود معلنة. لا تُنفذ الصيغ.
5. **المطابقة:** الاقتراح الآلي ليس موافقة. تُعرض المطابقات للمراجع ويُسجل القرار المعتمد وفاعله وتوقيته. الأعمدة غير المختارة والمناطق غير المدعومة تبقى محفوظة وغير معتمدة.
6. **اعتماد بحسب الكيان:** المسارات المدعومة حاليًا هي استيراد المديريات المتوافق مع النظام السابق، واعتماد صفوف مشاريع، واعتماد قياسات مؤشرات ذات مديرية وفترة ومؤشر معروف. لا تُحوّل المناطق العامة إلى كيانات بالتخمين.
7. **عدم الإتلاف:** غياب العمود أو فراغ الخلية لا يمسح قيمة قائمة. الصفر والحالات غير المعروفة وغير المنطبقة وغير المجموعة وغير المتحقق منها حالات متميزة. حذف قيمة يتطلب اختيارًا صريحًا وسببًا.
8. **الجودة والتتبع:** تُعرض ملاحظات الجودة المفتوحة والمسوّاة مع سبب التسوية ومصدر الاستيراد أو الكيان حيث يتوفر. تُسجل تغييرات النماذج والسجلات والقرارات ومصادر القيم.
9. **استكشاف البيانات:** تتوفر قوائم مرقمة وقابلة للبحث للسجلات المركزية وقياسات المؤشرات والمشاريع ومصادر البيانات والاستيرادات، مع ضوابط وضع المالك/المشاركة.
10. **التحليل والتقارير:** لا تتغير معادلات التحليل والترتيب المقبولة تلقائيًا بسبب إدخال سجلات معيارية جديدة؛ ربط القياسات الجديدة بها يحتاج قرارًا منهجيًا واختبارات تكافؤ.

## نموذج البيانات التنفيذي

يتضمن المخطط جداول تعريفات النماذج والحقول والأقسام والقيم المرجعية والوحدات والفترات والجغرافيا والسجلات والملاحظات الزمنية والمصادر والقيم وأصلها ونسخها ومراجعتها وسجل التدقيق ودفعات الاستيراد وأوراقها ومناطقها وصفوفها وخلاياها ومطابقاتها ومشكلات الجودة. وتُحفظ المشاريع وتمويلها ومرفقاتها وقياساتها في سجلات مخصصة.

الحقول الحالية للمديرية نقطة توافق ومصدر تعريف أولي، وليست قائمة مؤكدة بكل النماذج الإدارية المطلوبة. تواريخ البيانات القديمة غير المتوفرة تظل غير محددة؛ لا يستنتجها الترحيل من وقت تشغيل التطبيق.

## حدود التنفيذ الحالية

- التعريف المنشور المتاح حاليًا هو نموذج توافق حقول المديرية الحالية؛ الكتالوج الرسمي لجميع النماذج غير موجود في المستودع.
- الترقيات المخصصة متاحة للمديريات والمشاريع وقياسات المؤشرات؛ بقية مناطق Excel تُحفظ في الاستقبال فقط.
- المطابقة محلية وحتمية ومحدودة بقواميس وقواعد معروفة، ولا تستخدم تعلمًا آليًا أو تعلمًا من تصحيحات المستخدم.
- الصور تحفظ كوسائط خام عندما تستطيع المكتبة استخراجها؛ لا يوجد OCR ولا تصنيف دلالي ولا ربط تلقائي بالكيانات. المرفقات اليدوية متاحة للمشاريع، مع تصدير صريح؛ لا توجد معاينة داخلية عامة.
- صفحة مصادر البيانات الحالية للاستعراض والبحث، وليست محررًا لتغيير سجل المصدر التاريخي.
- التحليل الحالي يحافظ على جسر التوافق مع مخطط المديريات القديم؛ ليس كل سجل معياري جديد مدخلًا في اللوحات أو الترتيب.
- لا تعني حماية وضع المشاركة وجود حسابات أو مصادقة مستخدم متعددة العوامل.

## معايير القبول

- تُنشأ قاعدة جديدة وتُرقّى قاعدة سابقة وتُعاد الترقية دون حذف بيانات أو فشل جزئي.
- يفشل الاعتماد عند مطابقة غير صريحة أو مرجع/فترة غير موثوقة، وتبقى البيانات الخام قابلة للمراجعة.
- يثبت الاختبار أن الملف الجزئي لا يمسح القيم السابقة وأن الحذف الصريح وحده يغيّرها.
- يُحفظ المصدر وموضع الورقة/الصف/الخلية وقرار المطابقة في المسارات التي توفر هذه البيانات.
- تنجح اختبارات الوحدة والتكامل والبناء وElectron E2E على Linux وWindows قبل الدمج أو الإصدار.
- يُختبر استرجاع قاعدة البيانات ومفتاح التشفير معًا على بيئة Windows فعلية قبل اعتماد الاستعادة تشغيليًا.
- لا تُقدّم قائمة النواقص أعلاه على أنها وظائف مكتملة.

## قرارات خارج نطاق البرمجيات

لا يحدد الكود وحده شرعية تعريفات المؤشرات وأوزان الترتيب والحدود المرجعية وصحة القيم ميدانيًا. تتطلب هذه قرارات موثقة من الجهة المختصة ومصادر بيانات قابلة للتحقق.
