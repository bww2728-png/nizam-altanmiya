# نظام التنمية المحلية

تطبيق مكتبي عربي لإدخال بيانات التنمية المحلية وتحليلها محليًا، مع قاعدة SQLite مشفّرة (SQLCipher). تُعالج ملفات المستخدم وقيمه داخل الجهاز؛ الاتصال الخارجي الوحيد الذي ينشئه التطبيق هو فحص GitHub Releases وتنزيل تحديث عند توفره، ويمكن تعطيل الإنترنت على مستوى النظام إذا كانت سياسة الجهة تمنع أي اتصال.

## أول تشغيل

- لا توجد كلمة مرور. يولّد التطبيق مفتاح تشفير عشوائيًا (256 بت) مرة واحدة ويحفظه في `store.key` بجوار قاعدة البيانات.
- إذا وُجدت قاعدة بيانات وفُقد `store.key`، يرفض التطبيق العمل ويطلب استعادة المفتاح من مجلد `backups`. لا يولّد مفتاحًا جديدًا كي لا يجعل بياناتك غير قابلة للقراءة.
- إذا كان الملف الموجود ليس قاعدة يخص التطبيق (مفتاح مختلف)، تُنقل نسخة بايت-ببايت إلى `backups` قبل أي إجراء، ثم تُحجر القاعدة القديمة ويُبدأ متجر جديد.
- زر النسخ الاحتياطي في الشريط العلوي ينشئ نسخة في `backups` (يُحتفظ بأحدث 10).

## سير العمل

1. **قاعدة مستقلة**: قاعدة SQLite المشفّرة هي مخزن النظام المحلي؛ Excel وسيلة إدخال وأرشفة للمصدر وليست مخطط قاعدة البيانات.
2. **استقبال Excel**: يقرأ التطبيق جميع الأوراق والمناطق التي يمكن اكتشافها ضمن حدود الموارد، ويحفظ نسخة الملف وبصمته والخلايا والصيغ والقيم المخبأة والصور التي أمكن استخراجها في الاستقبال المحلي. لا تُنفذ الصيغ ولا يُستخدم OCR أو نموذج ذكاء اصطناعي.
3. **المراجعة والاعتماد**: المديريات والمشاريع وقياسات المؤشرات لها مسارات اعتماد صريحة بحسب نوعها. الاقتراحات لا تعتمد تلقائيًا، والصفوف المخفية أو ذات الصيغ أو المطابقات الغامضة لا تُرحّل. المناطق العامة غير المدعومة تبقى في الاستقبال دون اعتماد.
4. **الإدخال اليدوي**: صفحة الإدخال تقرأ تعريفات النماذج المنشورة من القاعدة، وتدعم المسودات والمراجعة والاعتماد وحالات القيم المختلفة، مع مصدر ونسخة وسجل تدقيق لكل تغيير. الكتالوج الرسمي للنماذج الـ105 غير متوفر بعد؛ لذلك لا تُفعّل سوى تعريفات موثوقة متاحة.
5. **السجلات المتخصصة**: صفحات مستقلة للمشاريع والتمويل والمرفقات، وقياسات المؤشرات المؤرخة، وسجل جودة البيانات، وسجل المصادر، وسجل تاريخ الاستيراد.
6. **التحليل**: لوحة التحليل والترتيب ما تزال محافظة على قواعد الحساب الحالية وجسر التوافق مع البيانات القديمة. السجلات المعيارية الجديدة لا تغيّر النتائج المقبولة تلقائيًا؛ يلزم قرار منهجي قبل ربط قياسات المؤشرات الجديدة بالترتيب.
7. **التصدير**: Excel (ثماني أوراق) أو PDF. التصدير للقراءة ولا يعدّل قاعدة البيانات، وتُحجب الحقول المصنفة عند تشغيل وضع المشاركة.

## الحقول الحساسة ووضع المشاركة

الschema يصنّف الحقول `public` / `restricted` / `sensitive`. زر الوضع في الشريط العلوي يبدّل بين:

- **مالك الجهاز**: كل الحقول ظاهرة.
- **وضع المشاركة**: الحقول المقيّدة والحساسة تُحجب في القراءة والتصدير، وكل قراءة محجوبة تُسجَّل. لا يمسح حفظ النموذج في هذا الوضع القيم المحجوبة، لأن الحقول المحجوبة تُستثنى من الكتابة أصلًا بدل إرسال فراغ.

## سجل التدقيق

- `access_log`: كل كتابة واستيراد (`excel-scan` / `excel-import`) وتصدير وتعديل أوزان.
- `audit_reads`: كل قناة قرأت بيانات — الكيان، الحقول المحجوبة، عدد الصفوف، الجلسة. تبويب «سجل التدقيق» يعرض الجدولين.
- `directorate_versions`: لقطة كاملة (السجل + مصادره) قبل كل تعديل أو حذف، مع استعادة ممكنة. يُحتفظ بأحدث 20 لقطة لكل مديرية.

## حدود معروفة

- زمن التحليل ينمو خطيًا: 5,000 صف ≈ 0.8s للإدراج و0.4s للتحليل، و20,000 صف ≈ 3.1s و1.7s. الحمولة عبر IPC تُقلَّم الآن (تُقرأ تفاصيل الصف عند الطلب).
- يُقرأ من الملف حتى 5000 صف كحد أقصى في القراءة الواحدة (`MAX_ROWS`)، وتُعرض الخطة كاملة عبر `importPlan`.
- لا يدعم XLS أو DOC القديم: الاستيراد يقبل `.xlsx` و`.xlsm` فقط.
- المديريات التي تنقصها حقول إلزامية أو تحمل قيمًا شاذة تبقى في القاعدة لكنها تُستبعد من الترتيب حتى تُصحّح.

## التطوير والاختبار

يلزم Node.js 22 أو أحدث. ثبّت الحزم من ملف القفل باستخدام `npm ci`، ثم:

- `npm run dev:desktop` لتشغيل التطبيق في بيئة التطوير.
- `npm test` لاختبارات قاعدة البيانات المشفّرة، والخرائط والمخطط، والاستيراد وخطته، والأوراق، والمحرك، والإدخال اليدوي، والتقوية الأمنية.
- `npx electron scripts/e2e-analysis.cjs` لاختبار شامل على التطبيق الحقيقي (41 فحصًا) مع أدلة في `نتائج-الفحص`.
- `npm run build` لبناء واجهة الإنتاج.
- `npm run dist:win` / `dist:win:zip` / `dist:win:dir` لبناء Windows x64.

الحزم غير موقعة رقميًا، لذلك قد يعرض Windows تحذير SmartScreen. قاعدة البيانات في مجلد بيانات المستخدم باسم `development-data.db`، والمفتاح في `store.key` بجوارها.
