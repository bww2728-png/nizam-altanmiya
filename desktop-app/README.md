# نظام التنمية المحلية

تطبيق مكتبي عربي لإدخال البيانات ومراجعتها محليًا، مع قاعدة SQLite مشفّرة. لا يرسل التطبيق ملفاتك إلى خدمات خارجية.

## الاستخدام

- عند التشغيل الأول، أنشئ عبارة مرور وأكدها. احفظها في مكان آمن؛ لا توجد آلية لاستعادتها.
- من «استيراد ملف»، اختر ملف Excel بصيغة `.xlsx` أو PDF بصيغة `.pdf` أو Word بصيغة `.docx`.
- تبقى جميع القيم المستخرجة مسودات للمراجعة. صحّح الحقل والقيمة، وأدخل المحافظة والمديرية والعزلة والتجمع/القرية، ثم اعتمد.
- عند تعارض حقل مع سجل موجود بالمفتاح الجغرافي نفسه، قارن المصدرين قبل اختيار الاستبدال.
- تصدير Excel ينشئ نسخة من السجلات المعتمدة فقط، ولا يعدل قاعدة البيانات.

## دقة الاستخراج وحدوده

الاستخراج آلي أولي وليس إثباتًا لصحة البيانات. يُحفظ لكل قيمة اسم الملف وموضعها في ورقة/خلية Excel أو صفحة/سطر PDF أو سطر Word. تُحفظ الأصفار كقيم صحيحة؛ الخانات الفارغة لا تتحول إلى صفر. عند انخفاض جودة PDF النصي، يستخدم التطبيق OCR عربيًا محليًا، لكن يجب مراجعة نتائجه قبل الاعتماد.

الحد الحالي للملف 40 ميغابايت، وللاستخراج 5,000 قيمة أو 250 صفحة PDF. يدعم Excel بصيغة XLSX وWord بصيغة DOCX فقط؛ لا يدعم XLS القديم أو DOC القديم. قد تحتاج الجداول متعددة الصفحات، والملفات الممسوحة ضوئيًا، والمستندات ذات التنسيق غير المنتظم إلى تصحيح يدوي. لا يعد التطبيق نتائج أو ترتيب أولويات تنمويًا قبل بناء مؤشرات موثقة واختبارها على بيانات ميدانية معتمدة.

## التطوير والاختبار

يلزم Node.js 22 أو أحدث. ثبّت الحزم من ملف القفل باستخدام `npm ci`، ثم استخدم:

- `npm run dev:desktop` لتشغيل التطبيق في بيئة التطوير.
- `npm test` لاختبارات قاعدة البيانات المشفّرة، المراجعة، وملفات Excel/PDF/Word.
- `npm run build` لبناء واجهة الإنتاج.
- `npm run dist:win` لإنتاج مثبت Windows x64 من بيئة البناء المناسبة. يشمل أمر البناء اعتماد Canvas الاختياري الخاص بـWindows x64.
- `npm run dist:win:zip` لإنتاج حزمة Windows x64 محمولة بصيغة ZIP؛ فك الضغط ثم شغّل `نظام التنمية المحلية.exe`.
- `npm run dist:win:dir` لإنتاج مجلد التطبيق غير المضغوط.

الحزم غير موقعة رقميًا، لذلك قد يعرض Windows تحذير SmartScreen. يتطلب إنشاء مثبت NSIS بيئة بناء متوافقة؛ لم يمكن إنتاجه من بيئة Linux ARM64 الحالية.

يحفظ التطبيق قاعدة البيانات في مجلد بيانات المستخدم الخاص بـElectron، باسم `development-data.db`. لا تُخزن عبارة المرور في التطبيق.
